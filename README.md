# Deep Learning Components

深度学习常用组件：RNN、LSTM、Embedding、BatchNorm、Dropout、Pooling 等手写实现与训练示例。

## 目录结构

- `adam_demo.py`
- `BatchNorm.py`
- `Dropout.py`
- `embedding_padding_demo.py`
- `LSTMforward.py`
- `Pooling.py`
- `RNNforward.py`
- `train_chinese_cls_rnn.py`
- `第三周深度学习组件.pptx`

## 快速开始

各示例代码可直接运行，具体参数见源码内注释。

## 说明

- 模型权重、向量库、安装包等大文件未纳入仓库，所需模型请按代码中的名称从 HuggingFace 或对应官方渠道下载。
- 请通过环境变量配置 API Key（如 `DASHSCOPE_API_KEY`、`DEEPSEEK_API_KEY`），仓库中不包含任何密钥。
